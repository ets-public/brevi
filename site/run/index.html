brevi.run

Compile, run and test Brevi without a toolchain.

A hosted service for coding agents. Send a Brevi program and its input, and get back the output, the test results or the error lines. Nothing to install, no Rust compiler on the agent's machine.

request
POST /run
{"code": "print(stdin().ints().sum())", "stdin": "3 4 5"}
response
{"ok": true, "stdout": "12\n", "ms": 41}

Not open yet. The service launches after the first public release of the Brevi compiler.

Learn about the language at brevi-lang.org.
