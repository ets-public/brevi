Compile and run your agent's Python with nothing to install

brevi.run will be the Brevi compiler as an API. An agent sends a Python or Brevi program with its input and tests, and gets back the output, the test results or the error lines. The agent's machine needs no Rust toolchain, no Python and no sandbox.

Who it is for

Agents that run in someone else's cloud, in a browser, or on a machine where nobody wants to install compilers.

run · check · test

The same tools as the MCP server

The calls brevi mcp serves locally, over HTTPS: check a program, run it with input, or run test cases and get ok or the first differing line for each.

sandboxed

Each program isolated

Every program runs in its own sandbox. It gets no files, network or environment unless the request grants them.

cached builds

Cached builds

Builds are cached by content, so when an agent reruns its tests after a one-line fix, only the changed program is rebuilt.

Until then, run Brevi yourself

The compiler is open source under Apache-2.0 and runs on Linux, macOS and Windows. brevi mcp gives any MCP client the same tools locally.
