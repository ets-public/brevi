Brevi is free, open source and archived

The compiler and everything in the repository stay open source under Apache-2.0. There will be no paid plans: Brevi Pro and the hosted run API are cancelled, and their waitlists are closed. Emails already on them are not used, shared or sold; reply to us on GitHub to have yours deleted.

Brevi was an experiment in compiling Python MCP servers and CLI tools into native binaries. On 19 November 2026 we built the ten most-downloaded Python MCP servers on PyPI, unchanged, with Brevi 0.28.3. None built natively: all ten needed the CPython bridge, and so Python on the run machine, and started at 1.00x to 1.16x CPython's time to the first tool call. Making them build would have meant copying large libraries one by one, so we stopped.

Read the post-mortemRead the real-server report

Brevi has no external security audit. Its sandbox is a policy layer, not an isolation boundary; run untrusted code in a container or VM.
