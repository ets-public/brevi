Run the Python your agent writes as a native binary

Your agent keeps writing ordinary Python. Brevi compiles it through Rust into a binary that prints exactly what CPython prints and runs 2 to 40 times faster on our benchmarks. When Brevi cannot build a file, it says why in one line of JSON.

Python in, Rust speed out

The model has no new syntax to learn and no guide to load. Brevi replaces python3 in the agent's loop.

  1. The agent writes Python

    Ordinary Python 3, with the standard library or installed packages, in one file or many. No type annotations needed.

  2. Brevi compiles it

    It infers the type of every value and writes Rust. Where a type changes at run time, it writes Rust over dynamic values instead. rustc makes the binary.

  3. Same output, less time

    The binary prints what CPython prints. If Brevi cannot match CPython exactly, it refuses at build time, and brevi run runs the file with python3 instead and says so in one line.

Speed and safety without asking the model for Rust

Models write Python most reliably, but CPython is slow and finds many mistakes only when the broken line runs. Rust is fast and safe, but it takes a model longer and costs more tokens to write. With Brevi the model writes Python and the program runs as Rust.

Same output as CPython

On 591 saved agent programs, every Brevi build prints exactly what CPython prints, byte for byte, with the same exit status. Codon builds 36 of them with wrong output.

refuses at build time

No silent differences

When Brevi cannot match CPython for some piece of Python, it stops at build time and names the line. It never builds a program that might answer differently.

{"line":N,"msg":…,"fix":…}

One-line errors

Build and run-time errors are one line that names the source line, a fraction of a traceback's tokens. The agent fixes that line and runs again.

allow read, write

Only the caller grants access

Under brevi run --sandbox and in the MCP tools, a program cannot read or write files, call native code or load libraries unless the caller allows it. allow lines in the source grant nothing.

numpy · pandas · tkinter

Installed packages work

Calls into numpy, pandas, sqlite3 and other installed packages run in CPython inside the native program. tkinter apps build too, and can be tested without a screen.

Rust stable · beta · nightly

Tested against new toolchains

CI builds daily on Rust stable and the newest and next Python, and weekly on Rust beta and nightly. Every benchmark program that once passed must keep passing.

One line per error

An agent pays for every token it reads. A Brevi error names the line, says what went wrong and, where it can, suggests a fix.

$ brevi check broken.pybefore running
{"line":8,"msg":"name 'totl' is not defined","fix":"did you mean total?"}

brevi check reports certain mistakes before the program runs, with a fix: a name that is never defined, a method no type has, text added to a number. Mistakes Python only finds at run time (an index out of range) fail there, as in CPython. In Brevi's own .bv language every type mistake is caught before it runs. How errors work
