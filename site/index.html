The fast, safe target for AI-written Python.

Brevi is built for AI coding agents. The agent writes the Python it already writes best; Brevi checks the whole program before it runs, answers each mistake with one short line the agent can act on, and builds a native binary that runs 2 to 40 times faster than CPython, with memory safety and overflow checks from Rust underneath.

Status: preview. The compiler, written in Rust, opens under the Apache-2.0 license with the first public release.

Why Brevi

Built for the agent in the loop.

Python is the language models have seen most and write most reliably. It is also slow, and it finds most mistakes only when the broken line finally runs, which costs an agent another round of reading and fixing. Rust is fast and safe, but slow and expensive for a model to write. Brevi lets the agent keep writing the Python it knows, and gives the result Rust's speed and checks: nothing new to learn, no guide to load, and errors made for a model to read.

Native speed from plain Python

Brevi builds a Rust binary from your .py files. On the 12 programs below, the same Python files run 1.7 to 40 times faster than under CPython with a plain brevi run, and level with Codon with --release.

checked before it runs

Mistakes found before running

Brevi works out the type of every value across the whole program and reports mismatches before the first run, where Python would fail halfway through, or not at all.

refuse, never guess

Same answer as Python, or a clear refusal

When Brevi cannot run a piece of Python exactly as CPython does, the aim is a clear refusal at build time, never a quietly different answer. A growing set of probe programs checks this against CPython.

one file to ship

One binary, no interpreter

The result is a single native executable. Nothing to install next to it: no interpreter, no virtual environment, no packages to match.

{"line":N,"msg":…,"fix":…}

Errors a model can act on

Each error is one JSON line with the line number and a suggested fix, a fraction of the size of a traceback. Small typos of known names are fixed during the build.

no guide to read

Nothing new for a model to learn

Agents write ordinary Python, so there is no language guide to load into every session. Brevi's own syntax and its guide are there for anyone who wants them.

Rust 1.99 · Python 3.15

Keeps working as Rust and Python move

Brevi is rebuilt every day on Rust stable and the newest and next Python, and every week on Rust beta and nightly. Each time, every benchmark program that ever passed is run again, so programs written today keep building as the toolchains update.

crates · Python packages

Not limited to the standard library

A program can split over several files, call any Rust crate from crates.io, and import numpy, pandas, sqlite3 or any other installed Python module, which runs through CPython inside the native binary.

Errors

One line per mistake, with the fix.

Brevi runs its own checks before Rust sees the code, in milliseconds. Anything Rust still rejects is mapped back to your line and rewritten in plain terms, so nobody reads generated Rust.

total.pyplain Python
import sys
n = sum(int(x) for x in sys.stdin.read().split())

For agents

Ready for coding agents from the first call.

The compiler ships with the pieces an agent needs to build, check and fix programs without a human setting anything up.

  • MCP server

    brevi mcp serves check, run, test, patch, edit, show and guide over stdio. The server keeps the program, so the agent sends it once and then only the lines that change.

  • Agent skill

    An Agent Skills package that tells the agent to write ordinary Python and build it with Brevi: skill.md.

  • llms.txt

    Machine-readable entry points at /llms.txt and /llms-full.txt, with the guide as plain Markdown at /guide.md.

  • Edit by name

    brevi patch f.bv p.bv replaces each function, type or test by name, so a fix costs only the lines that changed.

  • Libraries

    use "util.bv" splits a program over files, and use sha2 "0.10" with rust fn or py fn calls Rust crates and Python code: libraries.md.

  • Fast checks

    brevi check main.py --fast runs Brevi's own checks in milliseconds without invoking rustc.

brevi.run: compile, run and test in the cloud.
