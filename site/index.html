A programming language for AI models to write.

Brevi reads like Python and compiles to Rust. Models finish tasks in fewer tokens than in Python, the programs run at native speed, and every compiler error comes back as one short line the model can act on.

Status: preview. The compiler, written in Rust, opens under the Apache-2.0 license with the first public release.

for w, n in top:

Why Brevi

Built for the model in the loop, not for a person at a keyboard.

Every language in use today was designed for people. When a model writes code, the cost that matters is different: the tokens it writes, the error text it has to read, and the retries it needs before the program works. Brevi is designed around those three numbers.

up to 21% fewer tokens

Less to write, less to read

Counted end to end, including errors read and retries, models used fewer tokens in Brevi than in Python on five of six task sets and the same on the sixth, including tasks written after the language was tuned.

{"line":N,"msg":…,"fix":…}

Errors a model can act on

No file paths, columns or pages of notes. Each error is one JSON line with the Brevi line number and a suggested fix. Small typos of known names are fixed during the build.

2.90 s → 0.47 s

Rust speed and safety underneath

Brevi compiles to Rust and builds a native binary. The model never writes lifetimes, borrows or semicolons; ownership is worked out by the compiler.

True · .append() · range()

Python habits are accepted

Models write Python by reflex, so Brevi accepts the common spellings instead of rejecting them. Indented blocks, comprehensions, len(), sorted() and ", ".join(xs) all work.

4,665 tokens

The whole language in one short guide

A model reads one page before writing Brevi. The guide is built into the compiler, and brevi guide WORD prints only the lines about one name.

JSON · CSV · dates · decimals · regex

Batteries for everyday programs

Strings, lists, maps, files, JSON, CSV, dates, big integers, exact decimals, a min-heap and Python-syntax regular expressions are built in. No package setup before the first line.

Errors

One line per mistake, with the fix.

Brevi runs its own checks before Rust sees the code, in about 3 ms. Anything Rust still rejects is mapped back to the Brevi line and rewritten in Brevi's own type names, so the model never reads generated Rust.

For agents

Ready for coding agents from the first call.

The compiler ships with the pieces an agent needs to write, check and fix Brevi without a human setting anything up.

  • MCP server

    brevi mcp serves guide, check, run, test and patch over stdio. Each tool takes the program as text, so the agent needs no files.

  • Agent skill

    An Agent Skills package with setup and the write, check, fix loop: skill.md.

  • llms.txt

    Machine-readable entry points at /llms.txt and /llms-full.txt, with the guide as plain Markdown at /guide.md.

  • Edit by name

    brevi patch f.bv p.bv replaces each function, type or test by name, so a fix costs only the lines that changed.

  • Fast checks

    brevi check f.bv --fast runs Brevi's own checks in about 3 ms without invoking rustc.

Coming next

brevi.run: compile, run and test in the cloud.

A hosted service for agents that need to run Brevi without installing a Rust toolchain. Send a program, get the output or the error lines back. It opens after the public release of the compiler.
