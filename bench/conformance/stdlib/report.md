# CPython conformance

Brevi 0.27.1 against CPython 3.13.13 (tests from tag v3.13.13), 2026-11-13, linux.
Generated by `tools/conformance.py`; how to read and run it is in [bench/README.md](../README.md#cpython-conformance).

**Coverage 99.7%** (724 of 726 tests print exactly what CPython prints from a native build). **Wrong: 0** built programs gave a different answer (0 output, 0 exit code).

**Assertion-bearing coverage 93.9%** (682 of 726: native matches that printed something to compare; 43 matches print nothing). **Typed-path share 3.2%** (23 of 724 native matches took the typed build).

Forced dynamic build (`BREVI_DYN=1`): coverage 100.0%, wrong 0.

**Refused by design: 5** tests run a string as code (compile, exec or eval), which a sandboxed native binary refuses on purpose. They are left out of the coverage denominator and listed by name below.

**Need the string model: 0** tests stop on a str holding a lone surrogate, which Brevi's strings cannot hold yet. They count as not matched and are listed by name below.

**Call CPython-private helpers: 0** tests call a private module function (such as re._compile or functools._c3_mro) that Brevi refuses. They count as not matched and are listed by name below.
