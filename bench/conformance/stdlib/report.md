Generated by `tools/conformance.py`; how to read and run it is in [bench/README.md](../README.md#cpython-conformance).

**Coverage 98.1%** (622 of 634 tests print exactly what CPython prints from a native build). **Wrong: 0** built programs gave a different answer (0 output, 0 exit code).

**Assertion-bearing coverage 92.7%** (588 of 634: native matches that printed something to compare; 34 matches print nothing). **Typed-path share 2.9%** (18 of 622 native matches took the typed build).

**Refused by design: 4** tests run a string as code (compile, exec or eval), which a sandboxed native binary refuses on purpose. They are left out of the coverage denominator and listed by name below.

**Need the string model: 1** tests stop on a str holding a lone surrogate, which Brevi's strings cannot hold yet. They count as not matched and are listed by name below.

**Call CPython-private helpers: 6** tests call a private module function (such as re._compile or functools._c3_mro) that Brevi refuses. They count as not matched and are listed by name below.
