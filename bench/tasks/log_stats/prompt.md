Each stdin line is a web log entry `METHOD PATH STATUS MS`, for example `GET /home 200 35`. For each path, sorted alphabetically, print `PATH COUNT AVG P90 ERR%`: COUNT is the number of requests, AVG the mean of MS with 1 decimal place, P90 the smallest MS value such that at least 90% of that path's requests took that long or less, and ERR% the percentage of requests with STATUS 500 or more, with 1 decimal place followed by `%`. Ignore blank lines.
