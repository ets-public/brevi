# Leaderboard: tokens per finished task

Lower is better. Each figure is the total tokens a model spends to finish every task in the set: the code it writes, the error output it reads, and each retry counted as the lines it changed. Counts are exact (count_tokens). Generated by `bench/leaderboard.py` from `bench/logs`.

The held-out tasks (`ref/gen_big2.py`) were written after the language was tuned and never used to change it. The XL tasks (`ref/gen_big3.py`, 150 to 400 lines, two of them split over several files) were held out until their first two runs (x1, x2); Brevi was then improved over six rounds for the gaps the runs showed (x3 to x18, so the XL set is no longer held out); the figures are the latest round (x17, x18) against four Python runs (x1, x2, x15, x16). A second XL set (`ref/gen_big4.py`, runs y1 and y2) was written after v0.18 and is held out. Single runs vary by up to 30%, so each figure averages two or more runs.
