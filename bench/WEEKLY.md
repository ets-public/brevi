# Weekly agent-code benchmark

Generated by `bench/weekly.py render` from `bench/weekly.json`.

Each week Claude Sonnet and Claude Haiku solve the 24 tasks of the `rel` suite twice in plain Python: once checked with CPython, once checked and built with Brevi, with the same prompt. The whole API bill is counted, retries included. **Ratio** is Brevi's cost over CPython's (below 1.00x is cheaper). **Programs run** is the time the finished programs took on their tests, over the tasks both sides finished, and **Speed** is CPython's time over Brevi's. These test inputs are small, so most of each figure is process start-up; the [heavy tasks](../site/docs/benchmarks.md#heavy-tasks-and-the-plain-solution-line) show the gap on real work. The data is [bench/weekly.json](../bench/weekly.json) and every run's log is in [bench/logs/e2e](../bench/logs/e2e).
