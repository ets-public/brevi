# Axon benchmark

12 small stdin/stdout tasks (`tasks/`), each with tests generated by the reference solutions in `ref/gen.py`.
A model solves each task in one language and checks it with `run.sh LANG TASK FILE`, which logs every attempt to `logs/`.
`python3 analyze.py "logs/round1/*.jsonl"` prints the summary.

Token counts are estimates from `tokcount.py` (words, numbers and symbols), not a real tokenizer.
Set `AXON=/path/to/axon` when running Axon tasks.
