- Dynamic build: `vars(C)` and `C.__dict__` now hold exactly what CPython 3.13's type dict holds, in its order: `__firstlineno__`, `__static_attributes__`, the `__dict__` and `__weakref__` descriptors, `__slots__` member descriptors, ABCs' `_abc_impl`; no more Brevi-internal `__flags__`, `__abc_tpflags__` or `register` entries, and a namedtuple class has no extra `__eq__`/`__hash__`/`__lt__`/`__gt__`. Builtin types answer from CPython 3.13.13's own tables (`tools/gen_type_dicts.py`). A class Brevi cannot give exactly (an Enum, a dataclass, a typing class, a base of unknown layout, a class whose annotations Brevi did not keep) refuses instead of answering wrongly.
- Dynamic build: private names are mangled as CPython mangles them (`self.__x` in class `A` is `_A__x`, also in `vars()` of instances and in `__slots__`); before, they were stored unmangled.
- Dynamic build: `dir(x)` is supported, answered from those exact dicts (a module, or `dir()` without an argument, is refused). `C.q` for a `__slots__` name gives its member descriptor instead of raising.
- Dynamic build: docstrings are cleaned as CPython 3.13 cleans them (leading spaces and common indentation removed); `classmethod(GenericAlias)` works as a class's `__class_getitem__`; `locals()` in a class body starts with `__module__`, `__qualname__` and `__firstlineno__`.
