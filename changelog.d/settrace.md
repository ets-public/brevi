- Dynamic builds support `sys.settrace` and `sys.gettrace` with CPython 3.13's call, line, return and exception events, for programs whose traced code uses a checked set of statements (assignments, expressions, pass, return, raise, assert, if/elif/else, match/case, try/finally, defs and classes, each on one line). Anything else in a program that uses `sys.settrace` is refused when it is built, never traced differently. `tools/trace_fuzz.py` compares random programs from that set against CPython 3.13.
- `import dis` is refused in dynamic builds: a compiled function has no CPython bytecode to disassemble (it used to raise `TypeError` when run). `brevi run` runs such a program with python3.
