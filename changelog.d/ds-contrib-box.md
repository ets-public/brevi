- **`tools/ds_contrib.py` runs everything the model can influence in a box.** The compiler it edits, the programs it builds, its `try_python` snippets and the task check run in their own PID, mount and network namespaces as user `nobody`, with an allowlisted environment. There is no network, `/root` shows only the toolchains (read-only), and no other process, token file or session folder is visible. A self-check refuses to start a run if the box leaks. This replaces the name-based filtering of #372.
