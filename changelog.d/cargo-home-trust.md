- Security (v0.28.3): crate builds no longer use a cargo home another user can change. cargo runs what its home holds (`config.toml` can name a rustc wrapper; `registry/src` keeps crate sources it compiles without checking them again), and the sandbox image set `CARGO_HOME` to a folder every user could write, so one user could run code in another's native build. Brevi now uses `CARGO_HOME` (else `~/.cargo`) only if root or the user owns it and everything directly in it and no other user can write them, and otherwise says so and uses a private one. cargo also runs in Brevi's private build folder rather than the caller's, so a `.cargo/config.toml` left in a shared folder such as `/workspace` or `/tmp` is never read. The image no longer sets `CARGO_HOME`: each user's crates live in their own `~/.cargo`.
