- **Conformance: mixin test classes are scored.** CPython runs many functools tests through mixins (`class TestPartialC(TestPartial, unittest.TestCase)`), and the extractor used to skip their inherited tests without counting them. They are now extracted against the module's C copy. The pure-Python twins are excluded, since Brevi has one copy of each module and the C twin already scores it. This scores 91 more functools tests and shows 51 wrong results that had been hidden, now tracked as #446, #447 and #448.
