- **A repeated group over a long text no longer overflows the stack on the typed build.** `re.match('(x)*', 50000 * 'x')` and similar patterns crashed with a stack overflow, because the typed regex matcher recurses once for each repetition of a group. Long texts with such a pattern are now matched on a thread whose stack grows with the text. Found by the stdlib conformance slice (`test_re.test_stack_overflow`, `test_bug_418626`).
