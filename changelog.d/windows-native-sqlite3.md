- **Windows: native sqlite3.** Brevi's own sqlite3 now loads Windows' `winsqlite3.dll` from System32 with `LOAD_LIBRARY_SEARCH_SYSTEM32` instead of sending the program to CPython. A `sqlite3.dll` in the program's folder or CWD is never loaded; `BREVI_SQLITE_LIB` can name another absolute library outside the sandbox. Windows' SQLite version can differ from CPython's, so version-specific output may differ.
