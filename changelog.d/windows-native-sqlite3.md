- **Windows: native sqlite3.** Brevi's own sqlite3 now loads SQLite on Windows instead of sending the program to CPython: the `sqlite3.dll` beside the Python it was built with (so `sqlite_version()` and output match CPython), falling back to System32's `winsqlite3.dll`. `BREVI_SQLITE_LIB` still overrides the library. The loader never loads a bare `sqlite3.dll` from the program's folder or CWD.
