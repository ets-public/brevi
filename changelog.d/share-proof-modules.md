- The typed build's shared-list check now follows functions imported from a sibling file (`from util import f`) instead of taking every such call as one that may change its arguments, so multi-file programs that pass a list or dict to a helper in another file take the typed path again (the latency benchmark had fallen to the dynamic build in v0.27.0: `check --fast` after an edit 160 ms instead of 16 ms). It follows only what it can follow exactly (no `as`, and no module-level name of one file that the other reads or binds); anything else still refuses. `[0] * n` no longer refuses when `n` is a parameter the check knows nothing about. What the check requires of a module's code (the typed build sharing a list in place) is now checked at that module's own lines in the joined program, where it could before land on the main file's line of the same number.
