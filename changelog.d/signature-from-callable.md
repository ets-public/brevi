- Dynamic build: `inspect.Signature.from_callable` works for the program's own defs and lambdas, for functions that wrap them (`functools.wraps`, `lru_cache`, `singledispatch`, `singledispatchmethod`) and for bound methods, and its `str()` and `repr()` match CPython 3.13 exactly (positional-only `/`, `*`, defaults, annotations, return annotation). Any other callable (a builtin, a class, a `functools.partial`), a typing annotation, and the rest of the Signature API (`.parameters`, `==`, `hash`, `Signature(...)`) are refused instead of guessed. Three more CPython stdlib conformance tests match.
- Dynamic build: `lru_cache` wrappers' `cache_info` and `cache_clear` report CPython's `__qualname__` (`_lru_cache_wrapper.cache_info`).
- Dynamic build: `Signature.from_callable(functools.cmp_to_key)` and of the key function it returns match CPython (`(mycmp)`, `(obj)`). `copy.deepcopy` in a program that uses `itertools.tee` is now refused when the program is built, not when it runs.
