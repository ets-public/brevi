- **A first build on a fresh install no longer hangs.** The lock that makes concurrent builds of one library copy wait for each other was taken in a cache folder that did not exist yet on a new machine, so the first dynamic build of a program importing a library copy (mcp, jinja2, pydantic, ...) waited forever. The folder is now made first, and a lock that cannot be made for any other reason no longer blocks the build.
