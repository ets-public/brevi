- **Class `__annotations__` in the dynamic build.** A program that reads `C.__annotations__` gets the class's own annotations, evaluated as the class body runs, as in CPython; an instance finds them through its class's bases, and a class without any raises AttributeError from an instance. A program whose class annotations are type expressions (`int | None`, `list[int]`) is refused rather than run, and programs that never read `__annotations__` build as before.
