- Dynamic build: `weakref.proxy` works. Every operation goes to the referent while it lives (attributes, calls, `str`, truth, `len`, iteration, items, arithmetic, comparisons) and raises `ReferenceError` once it is gone; the proxy keeps its own type, repr and identity and is unhashable, as in CPython. A proxy with a callback, or of an object with `__index__`, `__int__`, `__float__` or `__complex__`, is refused. `re.Pattern` objects now take weak references. Four more CPython stdlib conformance tests match.
- Dynamic build: `iter(x)` of an object whose `__iter__` returns an iterator object now returns that object itself (`iter(it) is it`), as CPython does; before, it was wrapped, so its attributes were unreachable.
