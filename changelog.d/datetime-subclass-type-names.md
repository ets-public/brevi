- **Fixed two silent wrong answers in the dynamic build** (#421): `datetime.datetime` is now a subclass of `datetime.date` (`isinstance`, `issubclass`, `__mro__`, as in CPython), and library types named by a dotted CPython type name report CPython's `__name__`, `__qualname__` and `__module__` (`type(date(2020, 1, 1)).__name__` is `date` and its `__module__` is `datetime`; before, `datetime.date` and `builtins`). Error messages keep the dotted name, as CPython's do.
