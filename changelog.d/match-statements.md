- Python `match` statements (PEP 634) now build natively, over dynamic values: literal, capture, wildcard, value, sequence (with `*rest`), mapping (with `**rest`), class (with `__match_args__`), or-patterns, `as` and guards. Checks follow CPython's order (length checks, subscripts or unpacking, `get()`, attribute lookups), names are bound only when the whole pattern matches, and CPython's TypeErrors and ValueErrors for bad `__match_args__`, repeated attributes and duplicate keys are raised. A pattern CPython's compiler rejects (an unreachable case, a name bound twice, alternatives binding different names) refuses the build. CPython's test_patma goes from 0 to 266 of 323 tests matched with no wrong answers; the rest call compile() or sys.settrace.
- Fixed: a class built on dict or list and a collections.abc ABC (`class M(dict, Sequence)`) no longer fails to instantiate as abstract or raises "cannot be both Py_TPFLAGS_SEQUENCE and Py_TPFLAGS_MAPPING", and `isinstance(x, P)` for a Protocol class made inside a function is refused at build time instead of answering False.
