- **A fresh cache no longer hangs dynamic builds that use a library copy.** With an empty `~/.cache/brevi`, a program using numpy, onnxruntime or another bundled library waited forever for a build lock whose folder did not exist yet; the lock now makes its folder, and a lock that can't be made at all no longer blocks the build.
- **onnxruntime tests pass on onnxruntime 1.31.1.** 1.31 changes the last float32 digits of one encoder output in `tests/onnxruntime/inference.py`, which now prints that output rounded; Brevi's onnxruntime matches CPython's on 1.29 and 1.31 (pin bumped to 1.31.1).
