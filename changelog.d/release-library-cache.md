- **`brevi build --release` reuses Brevi's compiled library copies too.** Release builds now link jinja2, pydantic, httpx, polars, the MCP SDK and the other library copies from a library compiled once per toolchain and kept in the build cache, as debug builds already did, instead of recompiling them for every program. A `--release` build of an httpx program after a one-line edit went from 50 s to 4.8 s; the first release build that uses a library still pays for it once. The built programs run the same (callgrind instruction counts within 0.4% of a whole build). `BREVI_DYN_SPLIT=0` still builds each program whole.
