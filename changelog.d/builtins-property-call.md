- Dynamic builds: `builtins.property(...)`, `builtins.staticmethod(...)` and `builtins.classmethod(...)` called directly in a class body make the program's own descriptor (it printed `<property object ...>` before); properties also keep `fdel` and `doc`, run their deleter on `del obj.x`, and take `__doc__` from the getter.
- Dynamic builds: `property` is a type (`isinstance(x, property)` worked only as a TypeError, `type(p)` was `object`); a property wins over an instance `__dict__` entry of its name and over an attribute set before the property was put on the class; `property(f, fget=g)` raises CPython's TypeError instead of ignoring `fget`; reading a property with no getter gives CPython's "has no getter" message.
