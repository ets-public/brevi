- Fixed: `NPY_DISABLE_CPU_FEATURES` and `NPY_ENABLE_CPU_FEATURES` change which SIMD loops numpy runs (and so the last digits of its float32 `exp`, `tanh`, `log1p`, `sin` and `cos`), but a build ignored them and used Brevi's numpy, modelled on the CPU's own dispatch. With either set, or any other `NPY_*` / `NUMPY_*` setting, numpy programs now run with CPython's numpy, and the result cache keys on them.
