- **Faster method calls and attribute access in the dynamic build.** Class attribute lookups keep a two-way cache per class that no longer allocates on a miss; `o.x = v` on a class that has properties only takes the slow path for the property names; `type(x)` no longer hashes a class name; a missing instance attribute (as when `o.method()` looks in the instance first) is ruled out with one bit test; short attribute names compare as two machine words; `int * int`, `int % n` and `int // n` skip the general operator code. Rendering a chat template with jinja2 runs about 15% fewer instructions, a method-call loop is 8% faster, and `{{ m.role }}` on a plain dict no longer raises and catches an AttributeError inside Brevi's jinja2. New benchmarks against CPython are in `bench/speed/gaps/` (`sh bench/speed/gaps/run.sh`).
