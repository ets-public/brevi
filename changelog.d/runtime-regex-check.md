- Typed build: a regex pattern built at run time (`p = "(a)" + "\\1"; re.search(p, s)`) is now checked with the same rule as a literal one. Syntax the typed matcher lacks (back-references, named groups, look-arounds, `\ud800` escapes, CPython compile errors) stops the typed run, and `brevi run` runs the program again on the dynamic build, which gives CPython's answer. Before, such a pattern matched silently wrong. A program that cannot be run twice (it writes files) stops with an error that says why.
