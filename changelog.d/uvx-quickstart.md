- Docs: the quickstart, README, both sites, the PyPI README and the agent skills now lead with one command, `uvx --python 3.13 brevi run --verify main.py`, which fetches brevi, CPython 3.13 and the pinned Rust. No Rust install on Linux x86-64 and macOS from v0.28.2; Linux ARM64 and Windows need Rust from rustup until the next release.
- CI: `install-test` now runs that command as documented (uv, then `uvx`, then `uv tool install` for the demo) on a bare Ubuntu container with no C compiler, macOS with the runner's Rust removed, and Windows x64 and ARM64 (with rustup until the next release).
