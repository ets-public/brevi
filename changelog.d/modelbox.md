- **Model-written code runs only in a box, now for the release test too.** The box from `tools/ds_contrib.py` moved to `tools/modelbox.py` and got tighter: `/run`, `/home`, `/var/tmp` and `/dev/shm` are empty inside (no host sockets such as telemetry or databases), it has its own IPC and hostname, the whole box is killed on a timeout, and a self-check scans every file the box can read and refuses to start if one holds the value of any of the harness's secret variables. `bench/e2e.py` and `bench/replay.py` now build and run every solution a model writes in the box (they used to run with the full environment, so a solution that printed it would have sent the keys to the model's provider), with their own build cache. The DeepSeek harness may edit only `src/`, `tests/`, `compat/` and `docs/` (the files it commits), so it can no longer change scripts that run outside the box. `tests/modelbox_test.py` (in `tools/ci_local.sh`) checks the box holds and refuses a leaky one. The environment dump in one committed DeepSeek session log is removed.
