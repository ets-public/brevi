- **One table for every published number.** `docs/NUMBERS.md` is written by `tools/published_numbers.py` from the release tag's own conformance reports and `bench/compare/speed.json`: core 1,043 of 1,072 (97.3% of the scored suite, with 83 string-as-code tests excluded), stdlib 1,989 of 2,053 (6 excluded), assertion-bearing 88.2% and 94.3%, typed share 2.6% and 1.2%, and speed as typed median 9.3x against dynamic median 0.85x. CI (`--check`) refuses a stale table, any page, package README, agent skill, MCP text or release note that quotes the core headline share without that scope, and any that quotes a typed speed median without the dynamic one.
- **Release notes say which commit the numbers measured.** A release's reports measure the release PR's merge and the tag is the commit that adds them, so the two hashes differ (v0.28.1: measured `aa554040`, tagged `96a51afc`). The notes now name both and check that only reports and floors differ between them.
