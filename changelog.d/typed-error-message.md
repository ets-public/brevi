- Python files: `str(e)` of an error class of the program now gives CPython's message on the typed build in every case it can know (its args: what `super().__init__` got, or the call's positional args), instead of stopping the run with "str() of a E error is not supported yet". Cases it cannot know at build time (keyword or `*` args in the call, defaults, `super().__init__` inside an if or into the program's own base class, a list or object as the arg) now go to the dynamic build when the file is built. This also fixes two wrong answers on the typed build: an error made with a keyword arg (`E(key="k")`, where CPython's message is empty) and a field changed after the error was raised (CPython keeps the message it was made with).
