- A Python program that imports a module with top-level statements (a `print`, a loop, `__annotations__[1] = 2`) now builds natively over dynamic values, which run the module once on import as CPython does. Before, the normal build refused it with "a used file holds only fn, type, enum and test items" even though the dynamic build matched CPython. A `.bv` file's `use` keeps that rule.
