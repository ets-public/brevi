- Dynamic builds pickle the program's own functions and classes by reference, as CPython does: the pickle names the function's module and qualified name, dumping checks that the name finds the same object (a `PicklingError` or, for a def local to a function, an `AttributeError` otherwise), and loading gives back that very object. It used to fail with `TypeError: cannot pickle 'PyCapsule' object`. A builtin function or bound method of the program is refused with a clear error.
- `functools.total_ordering` fills in CPython's shared helpers (`_gt_from_lt` and the others, module `functools`), so `A.__gt__ is B.__gt__` holds as in CPython, and each helper looks the root comparison up on `type(self)` when called, so a subclass that overrides `__lt__` is used. Before, `__module__` read `__main__` and the root of the decorated class was always called.
