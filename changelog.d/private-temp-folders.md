- Security (Linux and other unix): Brevi's temporary folders (build folders, cargo projects, MCP work folders, the background build slots, and the folder a standalone binary unpacks its CPython into when there is no home folder) now live in a folder private to the user, `$TMPDIR/brevi-UID` (else `~/.cache/brevi/tmp`), used only when it is a real folder owned by the user with no access for anyone else, under folders no one else can change. Before, they were shared names in the temp folder that another local user could make first. With no private folder to use, brevi stops and says why. With no home folder, the cache moves into the private folder too.
