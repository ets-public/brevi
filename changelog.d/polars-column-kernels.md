- **Brevi's polars runs its per-row loops in Rust.** Comparisons, `+ - *` on int and float columns (with polars' integer wrapping), float sums, filters, row gathers, one-key `group_by` and building a column from a Python list now run as native column kernels (`_brevi_col`), with the same results as the Python loops they replace, which still run for anything the kernels don't model (big ints, nested values, mixed kinds). A 20,000-row filter, `with_columns` and `group_by` went from 0.30 s to 0.06 s (CPython with real polars: 0.02 s; was about 14x slower, now about 3x). New test `tests/polars/kernels.py` covers nulls, NaN, -0.0, mixed int/float comparisons, Int8/UInt8 wrapping and bool arithmetic.
