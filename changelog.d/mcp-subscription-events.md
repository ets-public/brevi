- **MCP change events are native.** A server on the official `mcp` SDK that calls `ctx.notify_tools_changed()`, `notify_prompts_changed()`, `notify_resources_changed()` or `notify_resource_updated(uri)` now builds with Brevi's own `mcp` instead of falling back to CPython. The events go to each open `subscriptions/listen` stream that asked for them, stamped with its subscription id, over stdio and over streamable HTTP. `MCPServer(subscriptions=...)` takes a custom bus, `mcp.server.subscriptions` (`InMemorySubscriptionBus`, `ListenHandler`) and `mcp.shared.subscriptions` are there for the low-level `Server`, and `resources/subscribe` / `resources/unsubscribe` handlers with `session.send_resource_updated` stay native for handshake-era clients. New tests (`tests/mcp_sdk/subs.py`, `subslow.py`, and a listen stream in the HTTP transcripts) match CPython's mcp 2.3.0 line for line.
