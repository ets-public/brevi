- Typed build: 7 of the 29 agent-written programs whose typed Rust failed to compile (path-split case study) now build typed and match CPython: `s * n` with a local str and a computed int, `print(a if c else b)` with branches of different plain types, `d.get(k, 0) + x` where the values are Decimal or float, a dict of Decimals read by a computed key (`RATES.get(tier, ZERO)`), and `s.split(None, n)`.
- Typed build: `split()`, `strip()`, `lstrip()`, `rstrip()`, `isspace()` and `Decimal(...)` now treat U+001C..U+001F as whitespace, as CPython's `str.isspace()` does (they printed different results before).
