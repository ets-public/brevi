- **Library copies are compiled once and reused.** A program that imports one of Brevi's library copies (jinja2, mcp, openai, pydantic, polars, ...) used to compile the whole copy, about 940 KB of Rust and 40 to 150 s of rustc, into every program. Debug and test builds now compile the copies into a separate cached library, keyed by its exact source, and build only the program against it, so the second jinja2 program builds in about 1 s instead of 98 s. Release builds (`brevi build --release`) are unchanged. Two builds that need the same library or runtime now wait for one build instead of both building it. A cold `tools/ci_local.sh --full` run on 4 cores went from 25 to about 15 minutes, with every check unchanged.
