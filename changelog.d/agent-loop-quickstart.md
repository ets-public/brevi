- Docs: Brevi is now pitched as the verified native runtime for agent-written Python. New [Quickstart for agents](https://brevi-lang.org/docs/quickstart) (install, write `main.py`, read the one-line JSON error, fix it, `brevi run --verify`), a runnable end-to-end demo in `examples/agent-loop/` (check, verify, a visible refusal, MCP, timing against CPython), and the install page now names the C linker `rustc` needs and the CPython 3.13 `--verify` compares against.
- CI: `install-test` workflow (by hand and on each release) runs the documented install on a bare Ubuntu container, macOS, Windows x64 and Windows ARM64, then the agent-loop demo.
