- Dynamic builds now give CPython's answer for `re.LOCALE` in Windows' default cp1252 locale (#589). The cp1252 codec (also `windows-1252` and `1252`) works for `bytes.decode`, `str.encode`, `bytes(s, "cp1252")` and `str(b, "cp1252")`, with every error handler and CPython's `charmap` errors. Bytes patterns under `re.LOCALE` take case and word characters from the C library in the environment's LC_CTYPE locale, as CPython's sre does, on every platform. Under `--sandbox`, which reads no environment, a `re.LOCALE` match stops the program instead of guessing the locale.
