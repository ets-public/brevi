- Crate lines are checked before anything reaches Cargo.toml: `use NAME "VERSION" "FEATURES"` needs a Cargo version requirement (`1`, `0.10`, `=1.2.3`, `>=1, <2`, `1.0.0-rc.1`) and Cargo feature names (`std`, `serde/derive`), and under `--sandbox` a crate with no version (which would build whatever crates.io serves that day) is refused, including one the rust code only names (`sha2::Sha256` with no `use sha2 "VERSION"` line).
- `brevi mcp --http`: after five wrong tokens in a row, an address (an IPv6 /64 counts as one) gets 429 for 1 s, then 2, 4, up to 60 s, without its token being checked; a right token clears the count. A server without a token (127.0.0.1 only) answers only local Host names (localhost, 127.0.0.1, [::1]) unless `--allow-host HOST` names another, so a page that rebinds its own name to 127.0.0.1 cannot reach it.
