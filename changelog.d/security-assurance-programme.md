- Security testing in the open: docs/SECURITY_TESTING.md lists Brevi's attack surface, its fuzz targets, checks and red-team attempts with their results, and docs/THREAT_MODEL.md now has a table of every place outside input reaches Brevi. Ten coverage-guided fuzz targets (`cargo +nightly fuzz`, in fuzz/) cover the parsers, the sandbox's capability check, MCP messages and grants, `brevi mcp --http` request framing, `--limit` values, folder grants and the standalone CPython bundle reader. CodeQL scans the code weekly.
- `brevi mcp`'s JSON reader refuses a number too large for a float (`1e999`), which it used to write back as `inf`, which is not JSON. Found by the new fuzzing.
