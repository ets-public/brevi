- **Sandboxed CPython gets no network without a grant (Linux).** Under `--sandbox`, a program that loads CPython (`--allow-py`, `--allow native`) and has no network grant now holds itself, before CPython starts, to no network with a seccomp filter: `socket()` fails with `PermissionError` for CPython, its C extensions and every process they start, Unix sockets by path included (`socketpair()` still works). A sandboxed program that starts CPython with hosts named by `--allow-net` is refused on every OS, since CPython cannot be held to those hosts: grant `--allow net` or leave CPython out. See docs/THREAT_MODEL.md.
