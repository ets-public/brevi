- Fixed a wrong answer: `locals().update(...)` (or any write through `locals()`) in an Enum's class body skipped the duplicate-name check, so a member set twice made the class where CPython raises `TypeError: 'A' already defined as 1`. In an Enum's body `locals()` is `enum.EnumDict`; Brevi's namespace is a plain dict, so the dynamic build now refuses `locals()` in the body of a class that may be an Enum (any base or metaclass other than a builtin the program does not rebind). Such a program runs in CPython instead (or, with `--strict`, does not build).
