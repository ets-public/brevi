- **More agent-written programs build typed.** `f(*T)` builds typed when T is a tuple literal set once at the top level, or a local or global set once from a function whose every return is a tuple of one length (`ok(*parse(sq))`-style code; it used to say "takes 2 arguments, got 1" and take the dynamic build). A compiled pattern's `pat.match(s, pos)` and `pat.search(s, pos)`, the loop of a hand-written tokenizer, build typed, with spans counted from the start of the text as in CPython. `float.is_integer()` (and `int.is_integer()`) build typed. Of the 676 Python programs agents wrote in `bench/solutions`, 453 built typed before this change.
