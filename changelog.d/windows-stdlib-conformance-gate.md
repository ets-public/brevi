- **Windows stdlib conformance gates a release.** The stdlib CPython conformance slice now has its own Windows floor (`compat/conformance_windows_stdlib_floor.json`) and known-wrong list (`compat/conformance_windows_stdlib_known_wrong/`), like the core slice. A release runs `tools/conformance.py --slice stdlib --check --release-gate` on the `brevi.exe` it ships, on x86-64 and ARM64, so a Windows stdlib wrong result or a score below the floor or 80% publishes nothing. The weekly Windows job runs both slices and raises both Windows floors on main.
