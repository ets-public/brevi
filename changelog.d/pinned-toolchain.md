- No Rust install needed: with no `rustc` on the PATH, brevi fetches the Rust release it is tested with on its first build, and zig to link with when the machine has no working C linker, each checked against a SHA-256 compiled into brevi and kept in Brevi's own folder. On by default on Linux (x86-64 and ARM64), macOS (Apple silicon and Intel) and Windows (x86-64 and ARM64; the GNU-ABI Rust with zig, so no Visual Studio), each checked by `pinned-toolchain.yml` on a real machine of that kind. Refused, with the reason, on an ARM64 Linux machine with a Cortex-A53 core and no C compiler (zig cannot apply the linker fix for its erratum 843419). `brevi toolchain` fetches now and prints what builds use; `BREVI_TOOLCHAIN=auto|system|pinned`, `BREVI_LINKER=cc|zig` and `BREVI_TOOLCHAIN_DIR` choose. `uvx --python 3.13 brevi run --verify main.py` is a whole install. install.sh no longer installs rustup where the pinned toolchain works.
