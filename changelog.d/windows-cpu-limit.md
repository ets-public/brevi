- `--limit cpu` now works on Windows. A Job Object holds the program and every process it starts: the kernel ends the job when its user-mode time reaches the limit, and a watch thread in `brevi`, which the program cannot stop or starve, ends it once user and kernel time together reach it (checked every 10 ms). `--limit file`, `fds` and `threads` stay refused on Windows, with messages that say why: Windows has no limit on one file's size or on a process's open handles, and a job cannot cap threads.
