- **A fuzzer for the builds** (`tools/fuzz.py`). It writes seeded random Python in the style agents write, runs it under CPython, then builds it on the normal and forced dynamic paths. A Rust panic, a signal or a compiler crash fails the run, and a wrong answer is reported. A failing batch is cut down to the one case that fails, and `--reduce` shrinks that case further. CI replays `bench/fuzz/corpus/` on every pull request, and the daily run fuzzes 60 fresh batches seeded by the date. The first 1,500 cases found no panics and three wrong-answer bugs (`0 ** -1`, the print order of set literals, the `chr()` error type), which are being fixed one PR each.
