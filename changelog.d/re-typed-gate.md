- The typed build's regex matcher no longer misreads syntax it lacks. A program whose pattern has a named group, a back-reference, a look-around, an atomic group, a possessive quantifier, `\B`, a scoped or mid-pattern inline flag, or a CPython compile error now builds on the dynamic path, which has the full syntax. A compiled pattern used as an object (`p.split(s)`, `repr(p)`, `print(p)`, `p.pattern`, `p.flags`) does the same. Before, the typed build gave wrong matches, or treated `p.split(s)` as `str.split`.
