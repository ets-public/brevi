- Wrong-answer fix: a dict filled with `d.setdefault(k, [..])` was read by the sharing proof as holding no lists, so two names for one of its items could print different values on the typed build (`x = d[k]; y = d.setdefault(k, []); y.append(9); print(x)` printed the old list). Such files now build over dynamic values.
- The sharing proof now follows `m = d[k]` / `m = d.setdefault(k, ...)` then `m[0] += v` while d is still read: the typed build writes m back right after each change, and the proof checks that it did (else the file builds over dynamic values). Programs like the FIFO stock and league solutions build typed again.
- `BREVI_DYN=0` no longer skips the wrong-answer guard: a file the guard sends to the dynamic build is refused instead of built typed (only the compiler's own typed tests skip the guard, with `BREVI_DYN=0 BREVI_GUARD=off`, never under `--strict`).
- Typed build: a loop over a JSON number, bool or None stops with Python's TypeError (`'int' object is not iterable`) instead of looping zero times.
