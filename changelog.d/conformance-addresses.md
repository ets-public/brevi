- **Conformance: object addresses no longer make a test "unstable".** A default repr such as `<function f at 0x7f...>` shows where the object sits in memory, so CPython printed something different on every run, and the scorer set those tests aside without counting them. Addresses are now blanked before outputs are compared, and the rest of the repr is still compared exactly. This scores 30 more stdlib tests: 6 match, and 20 tests were wrong without anyone seeing it. Those 20 are now tracked under #446, #447, #451 and #452. Stdlib coverage moves from 66.6% to 64.5%, which is the honest number.
