- **`re` in the dynamic build issues CPython's warnings**: a DeprecationWarning for a positional `count` or `maxsplit`, and a FutureWarning for possible set operations (`[a--b]`, `[[`, `&&`, `||`, `~~`). Each names the caller's line. With the `warnings` module they go through CPython's filters (`"error"` raises them). Without it they are printed to stderr as the default filters do. `count`/`maxsplit` are now read as an index (`re.I` is 2), with CPython's TypeErrors and OverflowError, and a positional `count` given again as a keyword raises CPython's TypeError (#418).
- **Bridged libraries:** a context manager's `__enter__` value stays live rather than being copied, and Python's builtin exception classes come back as the program's own, so `is`, `issubclass` and `except` agree with CPython (#438).
