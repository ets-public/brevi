- **Brevi's pydantic validates models faster again.** `object.__setattr__(obj, name, value)` in the dynamic build stores the attribute directly when no class from `object` on defines `__setattr__` (it used to copy the MRO and build a bound method for every call); a `str` field with no constraints returns the value at once; field validation reads the model's config once per model instead of once per validation, and skips tracking used keys unless `extra` is `forbid` or `allow`. Validating 50,000 nested models went from 1.35 s to 0.99 s (CPython with real pydantic: 0.11 s).
