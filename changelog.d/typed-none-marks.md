- A result equal to one of the typed build's marks for None (`-(2**62) * 2`, which is -2**63; `-1.7976931348623157e308`; `chr(0) + "None"`) printed None. It now runs on the dynamic build like an int past 64 bits. `int("123456789012345678901234")` on the typed build no longer raises ValueError.
- Re-running a program on the dynamic build after an int passed 64 bits no longer slows ordinary runs: the program writes straight to stdout and stderr and reads stdin itself (the prelude counts and hashes what it wrote, and keeps what it read from a pipe), so output and file input cost about the same as before (measured within 2%), and piped input about 1% more wall time and 3-5% more CPU. Past 64 MB of piped input the copy is dropped and an int past 64 bits stops with an error that says so.
