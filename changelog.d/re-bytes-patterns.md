- **`re` in the dynamic build matches bytes patterns** (they used to fall back to CPython). It follows CPython's rules: ASCII-only `\d\w\s\b` and case folding, `re.LOCALE` as the C locale (IGNORECASE sets test both cases of each byte), and bytes results from matches, `findall`, `split`, `sub`, `expand` and `escape`. Mixing str and bytes raises CPython's TypeErrors, and bad flag combinations raise its ValueErrors. `sub` with a template is faster on str as well.
