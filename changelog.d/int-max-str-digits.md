- **`sys.set_int_max_str_digits` and `sys.get_int_max_str_digits` work in dynamic builds.** `int(text)` past the limit (CPython counts the digits, not the sign, spaces or underscores, and only for a base that is not a power of two) and `str(n)` past it raise CPython's ValueError, with the limit set by the program (default 4300, 0 for none). Before, the setter did nothing and the getter refused the build. 12 more CPython `test_int` tests build and match.
