- Dataclasses in dynamic builds: a bare `ClassVar` annotation no longer becomes a field; `ClassVar[C]` and `Final[C]` over a class print, compare and hash as CPython's (`typing.ClassVar[int]`), so class annotations with them can be read and `make_dataclass` takes them; every dataclass has `__replace__`, as in Python 3.13; `class C(*bases)` builds; `copy.copy` and `copy.deepcopy` of a class with `__slots__` and its own `__setattr__` set the slots through it (a frozen dataclass with its own `__slots__` raises FrozenInstanceError, as in CPython).
- A Python file that calls a method named only in a string (`make_dataclass(..., namespace={'add_one': ...})`) falls back to the dynamic build instead of stopping with "no Python type has a method".
