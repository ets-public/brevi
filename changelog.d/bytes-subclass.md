- **Subclasses of `bytes` in the dynamic build**: `class B(bytes)` was refused at build time and now runs. Instances keep their class (`type`, `isinstance`, `__mro__`, slots and mixins), use bytes' methods (which return plain bytes, as in CPython), and work as `re` patterns and subjects (`Pattern.pattern` is the instance), with `memoryview`, `int()`/`float()`, `B.fromhex` (which returns a `B`) and `B.maketrans`. `re.sub` also takes a str-subclass replacement. Subclasses of `bytearray` and `memoryview` stay refused at build time.
- **`collections.abc.ByteString` refused in dynamic builds**: CPython warns (DeprecationWarning) when it is used with `isinstance` or subclassed, through a metaclass the dynamic build does not have, so a program that names it is now refused at build time instead of running without the warnings.
