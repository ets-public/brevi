- Dynamic builds: `k in sys.modules`, `sys.modules[k]` and `sys.modules.get(k)` answer as CPython 3.13 does, counting the modules it loads before a script runs (`"os" in sys.modules` is True). A read whose answer CPython does not fix is refused when the program builds: a module only some environments load at startup (encodings, sitecustomize, underscore modules), any module the program does not import before its other statements when it imports a library whose import loads others (json loads re), or after a codec lookup by name that may import more. A key that is not a string literal is refused when the program builds too, except a parameter of a def that the program only calls by name, with a string literal for it every time (each read is then decided as that literal is). `len(sys.modules)`, its keys, iteration and other methods, `from sys import modules`, and sys.modules reached through getattr or an alias are refused.
