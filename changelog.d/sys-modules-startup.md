- Dynamic builds: `k in sys.modules`, `sys.modules[k]` and `sys.modules.get(k)` answer as CPython 3.13 does, counting the modules it loads before a script runs (`"os" in sys.modules` is True). A read whose answer CPython does not fix is refused when the program builds: a module only some environments load at startup (encodings, sitecustomize, underscore modules), any module not imported by name when the program imports a library whose import loads others (json loads re), or after a codec lookup by name that may import more. A key known only at run time is decided there the same way and stops the program rather than guess. `len(sys.modules)`, its keys, iteration and other methods, `from sys import modules`, and sys.modules reached through getattr or an alias are refused.
