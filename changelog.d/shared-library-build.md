- **Programs that use different parts of one library now share its build.** The cached library of Brevi's copies now holds only the large copies (32 KB of Python or more) and what they import. Small re-export modules such as `mcp.types` or `mcp.server.lowlevel` build with the program, so MCP servers that import different ones share one library build: on a cold cache, five of the six MCP test servers now build in 2 to 8 s instead of about 100 s each.
