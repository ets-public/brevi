- Dynamic builds store module globals through `globals()` by a key known only at run time (`g = globals(); g['NAME_%s' % s] = v`), read them back by key, and run `Enum._convert_` (with a filter lambda that only reads the name) and `enum.global_enum`. A store that would rebind a def, class or import of the file, or add a name the program reads by name, stops the program instead of giving a different answer.
