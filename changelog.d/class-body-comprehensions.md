- **Comprehensions in a class body (dynamic build).** `class D: q = [i for i in range(2)]` failed to build in the dynamic build, and once built would have let the comprehension see the class's own names. Its variables are now plain locals, and past the first iterable it resolves names as CPython does: enclosing functions, globals and builtins, never the class namespace (also in Enum classes and classes that call `locals()`). A walrus inside such a comprehension is refused at build time, where CPython raises SyntaxError ([#442](https://github.com/ets-public/brevi/issues/442)).
