- Dynamic builds follow the descriptor protocol for the program's own classes, as CPython does: an object whose class defines `__get__` and is stored on a class is asked for the attribute (`obj.x` calls `__get__(obj, cls)`, `Cls.x` calls `__get__(None, cls)`), one whose class also defines `__set__` or `__delete__` handles assignment and `del` and wins over the instance's own attribute, and `__set_name__(owner, name)` is called when the class is made. Before, the descriptor object itself was returned and `__set_name__` was never called: a silent wrong answer.
