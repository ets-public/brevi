- **Generators run their cleanup as CPython's do.** `gen.close()`, and a generator dropped part way (its last reference gone, or still suspended at exit), raise GeneratorExit at the yield it stopped at, so `finally` blocks and `with` exits around a `yield` run. A generator that yields again is RuntimeError, and `close()` gives the generator's return value (Python 3.13). `gen.throw(exc)` and `gen.throw(type, value)` work on plain generators. `@contextmanager` functions with `try/finally` around their `yield` therefore build natively. Before, the dynamic build refused any `yield` inside `try/finally` or `with`.
