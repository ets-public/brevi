- **`type()` of an iterator names CPython's class** in the dynamic build: `list_iterator`, `str_ascii_iterator`, `dict_keyiterator`, `list_reverseiterator`, `map`, `zip`, `enumerate`, `generator`, `itertools.chain` and the other itertools types, a user iterator's own class, and, for a value from CPython, the type CPython reports. `type(a) is type(b)` holds for two iterators of one kind. An iterator whose class Brevi cannot name raises an error from `type()` instead of guessing, and `isinstance` of it against any other class is `False`, as in CPython.
