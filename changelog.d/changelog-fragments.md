- **Changelog entries go in `changelog.d/`.** Each PR now adds its entry as its own file in `changelog.d/` instead of editing CHANGELOG.md, so PRs no longer conflict on the changelog and rerun CI for it. `tools/changelog.py` prints the Unreleased entries, checks the files (in `tools/ci_local.sh` and CI) and, for the release PR, folds them into CHANGELOG.md under the new version (`--release vX.Y.Z`). The release notes, `tools/credits.py` and the site's changelog page read the fragments too.
