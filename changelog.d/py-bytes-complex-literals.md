- A Python file using a bytes literal with a raw prefix (`rb"a\d"`, `bR"..."`) printed a str (`a\d`) where python3 prints `b'a\\d'`: the typed build now refuses every bytes literal and the file goes to the dynamic build, which prints what python3 prints. Complex literals (`2j`) are refused the same way with a clear reason instead of "expected end of line, found j", and `u"..."` strings build typed.
