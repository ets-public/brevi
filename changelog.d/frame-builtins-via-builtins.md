- `locals()`, `globals()`, `vars()`, `dir()`, `eval()`, `exec()` and `breakpoint()` reached through the builtins module (`builtins.locals()`, `import builtins as b; b.vars()`, `getattr(builtins, "locals")`, `from builtins import locals as l`, `builtins.__dict__["locals"]`, `__import__("builtins")`, `sys.modules["builtins"]`) no longer build: native code has no Python frame for them, so they failed at run time with SystemError "frame does not exist" (and in an Enum body skipped EnumDict's duplicate-member TypeError). One reached through a module name computed at run time (`importlib.import_module(name).locals`) stops with Brevi's NotImplementedError instead of a SystemError.
