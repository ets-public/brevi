- Dynamic builds pickle the program's own int and tuple subclasses and namedtuples with CPython's bytes at every protocol (namedtuples used to pickle under module `_brevi_dyn` and load as another class), and run a class's own `__reduce__`, `__reduce_ex__`, `__getnewargs__` and `__getnewargs_ex__` in pickle and copy. `pickle.loads` runs the program's `__new__` and `__init__` at the point CPython runs them; a load whose objects would see a list, dict or set the load still adds to stops the program.
