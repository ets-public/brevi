- Dynamic builds run enum's pickle helpers: `enum.pickle_by_global_name` (also `_reduce_ex_by_global_name`) and `enum.pickle_by_enum_name` set as an Enum's `__reduce_ex__`, and `enum._make_class_unpicklable`.
- Fixed in dynamic builds: the class of an exception a Python library raised (`type(e)` of a `pickle.PicklingError`) is now the library's class for `is`, `==`, `hash`, `issubclass` (both ways), `__mro__` and `__bases__`, and calling it makes that exception. Before, `issubclass(type(e), pickle.PicklingError)` and `type(e) is pickle.PicklingError` answered False, and `issubclass(pickle.PicklingError, Exception)` raised TypeError.
