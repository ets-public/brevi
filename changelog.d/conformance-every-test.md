- **Conformance: the scorer now runs every test it used to skip as not extractable.** `tools/conformance.py` now handles tests that use `threading`, `locale`, `io.StringIO`/`BytesIO` and `unittest.mock`. It also handles a `with` statement that holds `subTest`/`assertRaises`/`assertWarns` together, `self.skipTest` and `self.addCleanup`, tests with default arguments, `exec` strings that call `self.assert*`, `from test.re_tests import ...` inside a test, `test.support.warnings_helper`, and `test_grammar`'s `typinganndata` modules, which are copied as pinned companion files. Core and stdlib now have no test left as not extractable (0 of 35, down from 35). The newly measured tests turned up 4 wrong answers in stdlib (#477 to #480), and they are tracked on the known-wrong list. A test CPython itself skips on the reference build (a missing locale, or no `_testcapi`) is excluded with that reason. Tests of CPython's own machinery are excluded with a stated reason: subprocess crash checks, `multiprocessing`, the deprecated `sre_*` modules, and `_testinternalcapi` recursion depth. Tests that call CPython-private helpers (`re._compile`, `functools._c3_mro`, and 4 others) are listed in `compat/conformance_cpython_private.txt` (#481). They stay in the denominator as not matched, and their count is printed beside every score. `--check` fails on a stale line there, or on a line without an issue.
