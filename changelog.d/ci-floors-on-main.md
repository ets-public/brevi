- CI: pull requests no longer raise the conformance floors. After each merge, main runs both slices on the merged tree and commits the floors it measures (`tools/conformance.py --check --raise-floor` in `conformance-main.yml`). `tools/floor_guard.py` fails a PR that raises one, and `--write-baseline` now only lowers them. Every conformance PR used to raise the same two numbers, so each merge put every other open PR into conflict. Each PR then had to merge main, re-measure and re-run CI (#483 ran 9 times).
