- Dynamic builds: every run-time refusal now stops the program instead of raising an exception a `try` could catch, as pickle and copy refusals already did. That covers the runtime's own refusals (for example `isinstance()` with `collections.abc.Callable[...]`, where an `except Exception` used to print a `NotImplementedError` CPython never raises), the "this program was built without ..." errors, and the refusals in Brevi's own copies of Python libraries (asyncio, polars, duckdb, sqlite3, mcp, safetensors, `open()`). A program can no longer go on with an answer CPython would not give.
