- `--strict` (or `BREVI_STRICT=1`) fails closed on any fallback, for CI and production jobs: only the typed build may answer (pybridge included), a file only the dynamic build takes is refused with one `{"e":"strict","path":"dynamic","line":...,"fn":...}` error, nothing runs with `python3` (`brevi-python` refuses every CPython handoff too), a typed run past 64-bit ints stops instead of re-running on the dynamic build, and every build prints its path line, typed too. It works with `run`, `build`, `check` and `verify`, and with `run --verify` as before. The release notes now give the share of conformance programs on each path, and `docs/SUPPORT_MATRIX.md` lists which constructs take which path on which platform.
