- Conformance tool: one disturbed CPython reference run no longer moves the score. A reference run that timed out, hit the memory limit or died on a signal is tried again and, if it fails twice, reported as not extractable ("CPython reference run failed at PYTHONHASHSEED=N"), never as unstable. Before a test is classed unstable, each seed's output must be reproduced by a second run at that seed: rule 1 (seeds 1 and 2 differ) and rule 2 (seeds 3 to 5, tried for a wrong result) both say which rule and seeds fired, and report.md lists every unstable test by name. On 11-14 a single disturbed run had dropped two deterministic tests (test_graphlib, test_re) from the stdlib score.
