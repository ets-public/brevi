- Dynamic builds take class keyword arguments (`class C(Base, flavor="x")`): they go to the base's `__init_subclass__`, to a metaclass's `__prepare__`, `__new__` and `__init__`, and `boundary=` sets an Enum Flag's `_boundary_`, with CONFORM and EJECT now handled as CPython's `Flag._missing_` handles them. Keywords that no `__init_subclass__` takes raise CPython's TypeError. Fixed along the way: an IntFlag with KEEP wrapped some negative values wrong (`A(-8)` gave 0 where CPython gives 8), and `from enum import STRICT` before the first use of `Flag` made `Flag._boundary_ is STRICT` false. Still refused at build time: an operator between members of two different IntFlag classes, and a Flag whose `__new__` makes its values with `<<` or `**` (values past 2**62).
