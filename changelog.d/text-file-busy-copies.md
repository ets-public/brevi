- Fixed: `brevi run` could fail with "Text file busy (os error 26)" when the build folder and the cache were on different file systems or mounts (a /tmp mount, for example), about one run in sixty with several at once. A cached program is then copied rather than linked, and the copy was written by a brevi process whose start-up thread could be starting a child that briefly held it open. Programs are now copied by a separate single-threaded helper process.
