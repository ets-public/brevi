- **DeepSeek as a contributor on CPython conformance.** `tools/ds_contrib.py TEST_ID` gives DeepSeek V4 Pro (reasoning effort max) one failing conformance test and a small set of tools: read, search and edit files in the repository (never `.git`, the harness or the test list), rebuild, rerun that one test, and build a snippet next to CPython. It cannot run other commands, push or reach the network. When it finishes, the harness reruns the test itself and, only if the test now matches on both builds and nothing that matched broke, commits the change on a branch with DeepSeek as the author. Spend is counted from the API's usage and capped per run (`--budget`, default $1.50); every step is logged to `bench/logs/ds_contrib/`. A person reviews each branch before it becomes a pull request, and DeepSeek's pull requests are never merged without review.
