- **Conformance: tests that run a string as code count as "refused by design".** A Brevi binary is compiled ahead of time and sandboxed by its caller, so it refuses `compile()`, `exec()` and `eval()` of a string on purpose. The tests that need them (25 core, 2 stdlib) are now named in the reviewed list `compat/conformance_by_design.txt` and left out of the coverage denominator. Their count is printed beside every score. `--check` fails on such a refusal that is not in the list, and on a listed test that is no longer refused that way, so the list changes only through a reviewed edit. Core reads 89.2% (257 of 288) against the 90% release gate, and stdlib reads 65.3%.
