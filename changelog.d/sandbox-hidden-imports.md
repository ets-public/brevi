- Security: under `--sandbox` (and the MCP tools), every import the parser finds is now checked, not only imports at the start of a line: an import after `;`, after a one-line `if`/`def`, or split with `\` is refused unless it is on a line of its own (or the caller grants `--allow native`). Brevi's child-process module (`asyncio.create_subprocess_exec`/`_shell`) now also checks the native grant itself on every call, and programs can no longer import Brevi's internal `_brevi_*` modules.
