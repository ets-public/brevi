- Dynamic builds pickle instances of the program's own classes on object, set or frozenset (dataclasses included) with CPython's exact bytes, and load them back; `copy.copy`/`copy.deepcopy` now honour a class's `__getstate__`, `__setstate__`, `__reduce__`, `__reduce_ex__`, `__getnewargs__` and `__new__` (they were silently skipped), and frozen `slots=True` dataclasses get `_dataclass_getstate`/`_dataclass_setstate` as in CPython.
- Dynamic builds give a class or def made under `global NAME` in a function CPython's module-level `__qualname__`, and load a pickle of a nested class of the program below protocol 4 (`getattr(Outer, 'Inner')`).
