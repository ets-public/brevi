- Dynamic builds: the enum functional API (`Enum('Color', 'RED GREEN')`, lists, pairs, dicts, `start=`, `type=`, `module=`, `qualname=`), `enum.property`, `ReprEnum` and `_member_type_` now build natively; a class's own `_missing_` and `_generate_next_value_` are used; `Enum.name`/`Enum.value` are read-only descriptors as in CPython, and "is not a valid" errors name the class's `__qualname__`.
