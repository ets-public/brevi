- `sys.setswitchinterval` and `sys.getswitchinterval` now work in dynamic builds. Brevi's green threads switch only at blocking calls, so the interval schedules nothing, but it is kept as CPython keeps it (whole microseconds, so `set` truncates and `get` gives `1e-6 *` that), with CPython's argument conversion and errors. An interval of 4294.967296 seconds or more, `nan` or `inf` is refused: CPython casts it to a C `unsigned long`, whose result differs by platform.
