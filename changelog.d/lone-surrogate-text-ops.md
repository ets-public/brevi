- Dynamic builds: text operations on a str holding a lone surrogate now match CPython: indexing, slicing, iteration, `*`, `str.join`, `%` formatting (`%s`, `%c` with a surrogate code point), `str.format`/`format_map`, `format()` and f-strings, and the str methods `split`, `strip`, `replace`, `find`/`index`/`count`, `startswith`/`endswith`, `partition`, `splitlines`, `center`/`ljust`/`rjust`/`zfill`, `expandtabs`, `removeprefix`/`removesuffix`, the case mappings and every `isX()` predicate. `encode`, `translate`, `re` and printing such a str still stop the program (#450, step 2).
- `'%c'` of an int outside range(0x110000) raises OverflowError, as in CPython, instead of giving `'?'`; `'%c'` of a str longer than one character raises TypeError.
- `str.replace` returns the str itself when there is nothing to replace, as CPython does.
