- Dynamic builds: every refusal on the pickle and copy paths (a class's own `__reduce__`, a bound method, a deque or iterator Brevi cannot pickle as CPython does, and the rest) now stops the program instead of raising an exception a `try` could catch, so a program can no longer go on with an answer CPython would not give. `copy.copy`/`copy.deepcopy` of an object whose `__reduce__` gives a tuple of the wrong length now raises CPython's own `TypeError` instead of a refusal.
