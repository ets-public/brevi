- **Releases carry an SBOM and signed provenance, and are checked for reproducibility.** Each release attaches `brevi-sbom.cdx.json` (CycloneDX: Brevi's crates, the Rust standard library, and every archive with its SHA-256) and GitHub build-provenance attestations for every archive, the SBOM and SHA256SUMS; check one with `gh attestation verify FILE -R ets-public/brevi`. The release workflow also builds the Linux x86-64 binary again from a fresh checkout in another folder and refuses to release unless the two are byte-identical.
