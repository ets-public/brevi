- **A bytearray passed to array, struct or zlib in the dynamic build**: `array.frombytes(bytearray(...))`, `array.array('B', ba)`, `a.extend(ba)`, `struct.pack_into`/`unpack`/`unpack_from` (and `struct.Struct`'s), `zlib.crc32`/`compress` and the other C functions of these modules take a bytearray, or an instance of a bytearray subclass that defines no methods, and their writes reach the program's bytearray, as in CPython. Each call gets a copy that is copied back afterwards, so it is allowed only when the call's other arguments are plain values (no program code can run during it); a library that keeps the bytearray after the call (`struct.iter_unpack`) stops with NotImplementedError, and a bytearray passed to any other CPython-run library is still refused.
