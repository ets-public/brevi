- `re.IGNORECASE` now works with any Rust toolchain: it folds case with CPython 3.13's own tables (generated into `src/unicode.rs` and checked against every code point) instead of rustc's, whose Unicode version follows the toolchain. On Rust 1.100 (Unicode 18) and newer, Unicode `re.IGNORECASE` patterns were refused at build time; on Rust older than Unicode 15 they were refused too. CI's pinned Rust moves to 1.100.0.
