- **Typed path: `except ZeroDivisionError` and `except IndexError`.** A `try` that catches these no longer sends the program to the dynamic build: inside such a try, and in every function it can reach (directly, through methods, or through `map`/`sorted` lambdas), division, modulo and indexing raise a catchable error with CPython's message; code outside such tries is unchanged. An uncaught `raise ValueError` with no message now reports the class name. On the agent-program corpus 5 more programs build typed (571 to 576 of 833), and every one prints what python3 prints. Written by DeepSeek through `tools/ds_contrib.py`.
