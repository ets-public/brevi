- **ONNX Runtime works on Windows.** Brevi's own onnxruntime copy now loads onnxruntime.dll with LoadLibraryA and gets the C API through OrtGetApiBase, skipping a loaded library that is not ONNX Runtime's (an old wheel's onnxruntime_providers_shared.dll). Model, optimized-model and profiling paths reach the C API as the UTF-16 ORTCHAR_T strings it uses on Windows. On Windows x64 with onnxruntime 1.16 or later (`pip install -U onnxruntime`; 1.13 and earlier wheels ship no capi/onnxruntime.dll), a minimal InferenceSession program runs natively and `brevi verify` says identical.
